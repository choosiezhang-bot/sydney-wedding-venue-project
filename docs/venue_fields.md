# Venue fields to capture (longlist)

- Venue name
- Suburb / address
- Style tags (waterfront/garden/hotel/warehouse/heritage/church)
- Capacity (seated / cocktail)
- Price ($/head) + inclusions
- Minimum spend / venue hire fee
- Hidden fees (service, overtime, AV, corkage, cakeage)
- Availability notes
- Reviews (rating, count, key themes)
- Photos links (official / real weddings / maps)
- Pros / cons / risks
- Contact name + email + phone
